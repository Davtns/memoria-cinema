#  Cinema Memoria
 
> Revivendo os classicos que o tempo esqueceu.
 
##  Sobre
 
O Cinema Memoria e uma plataforma criada para reviver filmes classicos que marcaram geracoes. Aqui voce podera descobrir obras esquecidas, assistir a trailers, avaliar filmes e explorar a historia do cinema.
 
## Funcionalidades
 
-  Catalogo de filmes
-  Pesquisa inteligente
-  Avaliacoes da comunidade
-  Comentarios
-  Favoritos
-  Maquina do Tempo
-  Trailers
 
##  Tecnologias
 
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
